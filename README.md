## 🚀 Overview

**Shields.io Badge Maker** simplifies creating customized status badges for GitHub project `README.md` files, documentation sites, and personal profiles. Instead of constructing raw URL strings manually, this tool gives you real-time visual previews, simple-icon search, palette pickers, and single-click copying for Markdown, HTML, and reStructuredText formats using standard badge styles.

---

## ✨ Features

- 🎨 **Real-time Preview:** Instant badge rendering powered by `img.shields.io`.
- 🔍 **Simple Icons Integration:** Search over 2,500+ brand and language logos with automatic slug lookup.
- 📐 **All Badge Styles Supported:** Default (`flat`), `flat-square`, `for-the-badge`, `plastic`, and `social`.
- 📋 **One-Click Export:** Copy ready-to-use snippets in **Markdown**, **HTML**, or **RST**.
- 🛠️ **Custom Color Pickers:** Use custom Hex codes, named colors, or popular brand palette presets.
- 📁 **Preset Collections:** Quick templates for Tech Stacks, CI/CD, Licenses, Downloads, and Social Links.
